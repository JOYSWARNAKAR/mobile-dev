# React Native Sign-In UI

A modern, responsive sign-in user interface built with React Native and Expo. This project showcases a beautiful authentication screen with smooth interactions, intuitive form handling, and cross-platform compatibility (iOS, Android, and Web).

## Screenshots

![alt text](<assets/sign-in-image-mobile.jpeg>)

## Tech Stack

- Framework: Expo 54 with Expo Router
- Language: TypeScript
- UI: React Native 0.81

## Getting Started

### Prerequisites
- Node.js and npm

## 🚀 Installation

1. **Clone or navigate to the project directory:**
   ```bash
   cd React-Native-Sign-In-UI
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm start
   ```
